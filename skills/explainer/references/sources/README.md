# Fuentes primarias y estado de verificación

Usa este directorio para rastrear **qué afirma cada perfil o framework sobre un estándar o método ajeno**. Las referencias de fuentes se resuelven desde la raíz de la skill (`references/sources/...`). Aquí solo se conservan enlaces y notas breves; no se incorpora el texto completo de normas con derechos de autor.

## Fuentes verificadas

- **ASD-STE100:** `references/sources/asd-ste100.md`. Páginas oficiales del ASD Simplified Technical English Maintenance Group (STEMG). Respaldan qué es el estándar, su estructura, ejemplos de vocabulario y cómo pedir la edición oficial.
- **Golden Circle / why-how-what:** `references/sources/golden-circle.md`. Página de Simon Sinek sobre WHY, HOW y WHAT. El framework de Explainer es una adaptación explicativa, no una copia normativa del método.
- **ISO 24495-1:2023 / `plain-language`:** `references/sources/iso-24495-1.md`. El catálogo oficial de ISO es inaccesible desde este entorno (403); las pautas se apoyan en el resumen público de la Federación Internacional de Lenguaje Claro, promotora del estándar. No se ha comprobado la norma íntegra.

## Sin especificación oficial verificada en esta skill

- **`feynman`:** perfil pedagógico inspirado en una técnica asociada a Richard Feynman. No se ha identificado una especificación oficial de esta «técnica» ni debe presentarse como un estándar o como una lista de pasos prescrita por Feynman.
- **`scqa`, `pyramid`, `what-so-what-now-what`:** referencias operativas para organizar explicaciones. Por ahora no se adjunta una fuente primaria verificada que autorice atribuir a terceros una formulación exacta. No afirmes autoría ni cumplimiento de un método original con estas fichas.

Antes de añadir fuentes, comprueba que la URL lleva al editor u organización responsable y que respalda la afirmación concreta. Si la fuente no está disponible, no rellenes huecos con memoria o resultados secundarios. Los enlaces pueden cambiar; vuelve a comprobarlos antes de publicar afirmaciones normativas o actuales.
