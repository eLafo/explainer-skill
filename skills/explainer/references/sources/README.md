# Primary sources and verification status

Use this directory to track **what each profile or framework claims about a third-party standard or method**. Resolve source references from the skill root (`references/sources/...`). Only links and brief notes are stored here; complete copyrighted standards are not included.

## Verified sources

- **ASD-STE100:** `references/sources/asd-ste100.md`. Official pages from the ASD Simplified Technical English Maintenance Group (STEMG). They support claims about what the standard is, its structure, vocabulary examples, and how to request the official issue.
- **Golden Circle / why-how-what:** `references/sources/golden-circle.md`. Simon Sinek’s page about WHY, HOW, and WHAT. Explainer’s framework is an explanatory adaptation, not a normative copy of the method.
- **ISO 24495-1:2023 / `plain-language`:** `references/sources/iso-24495-1.md`. The official ISO catalog is inaccessible from this environment (403); the guidelines rely on the public summary from the International Plain Language Federation, which promoted the standard. The full standard has not been reviewed.

## No verified official specification in this skill

- **`feynman`:** a teaching profile inspired by a technique associated with Richard Feynman. No official specification of this “technique” has been identified, and it must not be presented as a standard or as a sequence of steps prescribed by Feynman.
- **`scqa`, `pyramid`, `what-so-what-now-what`:** operational references for organizing explanations. At present, no verified primary source is attached that supports attributing an exact formulation to a third party. Do not claim authorship or conformity with an original method based on these references.

Before adding sources, verify that the URL belongs to the responsible publisher or organization and supports the specific claim. If the source is unavailable, do not fill gaps from memory or secondary results. Links can change; verify them again before publishing normative or current claims.
