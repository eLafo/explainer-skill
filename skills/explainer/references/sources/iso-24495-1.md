# ISO 24495-1:2023 — plain-language sources

- [Official ISO catalog: ISO 24495-1:2023, *Plain language — Part 1: Governing principles and guidelines*](https://www.iso.org/standard/78907.html). The official page returns 403 from this environment; **the full standard has not been read**. Do not present this reference as a conformity assessment.
- [International Plain Language Federation: ISO plain language standard](https://www.iplfederation.org/iso-standard/). The Federation promoted development of the standard. Its accessible page identifies the 2023 edition, states that it is language-neutral, and summarizes four principles: relevant, findable, understandable, and usable. It also states that the standard addresses writing, structure, and design, not vocabulary alone.
- [International Plain Language Federation: plain-language definition](https://www.iplfederation.org/plain-language-definitions/). Defines plain communication by whether intended audiences can find, understand, and use the information they need; includes translations of the definition into multiple languages.

**Scope of this reference:** these sources support an operational adaptation of published principles, not the complete requirements of ISO 24495-1 or a certification system. Before claiming that a document conforms to the standard, consult the complete official edition and test the result with real readers from the intended audience.
